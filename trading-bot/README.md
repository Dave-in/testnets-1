# Крипто-бот (Binance, Bybit и др.)

Спотовый бот **без плеча и без шортов**, работает полностью автоматически.
Подключение к биржам через [ccxt](https://github.com/ccxt/ccxt) (Binance, Bybit, OKX и ещё ~100 бирж).

Цели, принятые решения и открытые вопросы записаны в [PROJECT_NOTES.md](PROJECT_NOTES.md).

## Сигнальный бот в Telegram (быстрый старт)

Бот следит за монетами Binance, раз в сутки принимает решения и присылает в Telegram
сигналы «купить / продать». Каждую сделку он сразу исполняет на **виртуальном счёте**
(реальные цены, комиссии учтены) и отчитывается по результату. Реальных денег и ключей биржи не нужно.

```bash
cd trading-bot
python3 -m venv .venv && source .venv/bin/activate && pip install -r requirements.txt
cp .env.example .env
```

1. В Telegram напишите [@BotFather](https://t.me/BotFather) → `/newbot` → получите токен.
   Впишите его в `.env` как `TELEGRAM_BOT_TOKEN=...`.
2. Откройте своего бота, отправьте ему `/start`, затем выполните `python -m bot tg-setup`.
   Команда покажет ваш `TELEGRAM_CHAT_ID`. Впишите его в `.env` и запустите `tg-setup`
   ещё раз: должно прийти тестовое сообщение.
3. Запуск: `python -m bot --config config.signals.toml run`

Что приходит в Telegram:

- 🟢 **КУПИТЬ / ДОКУПИТЬ**: цена, сумма, доля счёта, уровень стопа;
- 🔴 **ПРОДАТЬ** / 🟠 **СОКРАТИТЬ**: цена, причина, итог сделки в USDT и процентах;
- 🌧 / 🌤 смена режима рынка (бот уходит в USDT или возвращается);
- **отчёт за день** в 00:00 UTC: счёт, результат за день, месяц и с запуска, позиции, статистика сделок;
- ⚠️ предупреждения: лимит просадки, потеря связи с биржей.

Команды боту: `/status`, `/report`, `/pause`, `/resume`, `/closeall`, `/help`.
Бот слушает команды только из чата `TELEGRAM_CHAT_ID`.

**Круглосуточно на VPS:** готовый systemd-сервис лежит в `deploy/trading-bot.service`
(инструкция внутри файла). Состояние хранится в `state/`, после перезапуска бот продолжает с того же места.

### Стратегия сигнального бота и её результаты на истории

Конфиг `config.signals.toml`. Только спот, только покупки, без плеча.

- **Фильтр рынка:** торгуем, только пока BTC выше своей 200-дневной средней. Иначе всё в USDT.
- **Вход:** цена монеты выше EMA20, EMA20 выше EMA100, и за 30 дней монета выросла.
- **Отбор:** из 9 монет держим до 4 самых сильных.
- **Размер:** по волатильности, цель 25% годового риска счёта.
- **Выход:** трейлинг-стоп (максимум − 3.5·ATR), слом тренда или плохой режим рынка.
- **Защита:** с просадки −5% позиции урезаются, на −15% и глубже торгуем на 40% размера.

Бэктест на реальной истории Binance, 01.2019–11.2026, с комиссиями:

| | Весь период | 2019–2022 | 2023–2026 |
|---|---|---|---|
| Доходность годовая | 27% | 48% | 9% |
| Средний месяц | +2.4% | +3.8% | +0.9% |
| Макс. просадка | 22% | 21% | 22% |

По годам: 2019 +14%, 2020 +58%, 2021 +177%, 2022 −4%, 2023 +26%, 2024 +14%, 2025 −4%, 2026 ≈0%.
Месяцы распределились так: 37% в плюс, 37% в минус, 26% без сделок (бот в USDT). Прибыль приходит рывками в бычьи периоды.
Последние четыре года заметно слабее первых — это главный риск стратегии.

Два готовых конфига:

| | `config.example.toml` (консервативный) | `config.aggressive.toml` (цель 6%/мес) |
|---|---|---|
| Активы | ETH (профиль `core`) или ETH/BTC/SOL/BNB | ETH, BTC, SOL, BNB, XRP, DOGE, AVAX, LINK, ADA: держим до 4 сильнейших |
| Риск | ~12% годовой волатильности | ~60% годовой волатильности |
| Лимит просадки | 6.5% | 25% |
| Сигналы | EMA 50/200, импульс 90 дней | EMA 20/100, импульс 30 дней |

Проверка на реальной истории Binance (2019–2026) показала, что оба этих конфига хуже сигнального:
консервативный дал 3% годовых при просадке 16%, агрессивный — 77% годовых при просадке **56%**
(лимит в режиме `pause` не удерживается: серии стопов складываются). Основным считается
`config.signals.toml`; эти два оставлены для сравнения.

Путь к запуску на реальные деньги проходит три этапа:

1. **Бэктест**: прогон по истории, смотрим доходность и просадки.
2. **Paper**: бот работает в реальном времени на реальных ценах, но с виртуальными деньгами.
3. **Testnet**: настоящие ордера на тестовой бирже (Binance Spot Testnet / Bybit Testnet).

Live-режим (реальные деньги) есть, но заблокирован двойным подтверждением.

## Как работает стратегия

| Что | Как |
|---|---|
| Вход | Только в устойчивый рост: `close > EMA50 > EMA200` и цена выше, чем 90 дней назад |
| Выход | Трейлинг-стоп `макс. закрытие − 3·ATR` или слом тренда (`close < EMA200`) |
| Размер позиции | По волатильности: цель ~12% годовой волатильности портфеля. ETH (~70% вол.) получает ~15–20% капитала, остальное лежит в USDT |
| Корреляции | Если активы ходят вместе (а в крипте почти всегда), общий размер урезается |
| Защита от просадки | С −2.5% от пика позиции плавно уменьшаются; при −6.5% бот закрывает всё и встаёт на паузу |
| Комиссии | Мелкие подстройки пропускаются, чтобы комиссии не съедали доход |

**Профили** (в `config.toml`):
- `core`: только ETH;
- `balanced`: ETH 50%, BTC 40%, SOL 15%, BNB 15% (это максимальные доли, реально меньше из-за контроля волатильности).

Можно добавить свой профиль с любыми парами.

### Честно о цифрах

- Лимит просадки 6.5% жёстко соблюдается в режиме `hard_stop_action = "halt"`:
  после срабатывания бот останавливается и ждёт вас. Нарушить его может только
  обвал «гэпом» между проверками цены.
- В режиме `"pause"` бот после паузы продолжает торговать с урезанным риском.
  Каждая серия ограничена ~6.5%, но несколько неудачных серий подряд в сумме
  могут дать больше (на синтетических тестах выходило 8–15%).
- **Про цель 6% в месяц.** Ровные +6% каждый месяц не даёт ни одна публично известная
  стратегия без большого скрытого риска. Агрессивный трендовый бот зарабатывает
  рывками: несколько месяцев по +20–80%, между ними нули и минусы, просадки 25–40%.
  Таблица «год × месяц» в отчёте показывает, как часто цель выполнялась на истории.
- Плата за низкую просадку — низкая доходность. Если ETH упадёт на 30%, а бот
  держит в нём 15% капитала, вы потеряете ~4.5%, но и при росте ETH на 30%
  заработаете ~4.5%. Ждать 70% годовых при просадке 7% нереалистично. Чего
  ждать на самом деле, покажет бэктест на реальной истории.
- Бэктест не гарантирует будущее. Поэтому после него идут paper и testnet.

## Этап 1. Бэктест по истории

```bash
# Скачать дневные свечи (Binance, все пары из всех профилей) с 2018 года
python -m bot download --since 2018-01-01

# Бэктест профиля core (только ETH) с 2019 года
python -m bot backtest --start 2019-01-01

# Агрессивный конфиг (цель 6%/мес)
python -m bot --config config.aggressive.toml download --since 2019-01-01
python -m bot --config config.aggressive.toml backtest --start 2020-01-01 --out reports/aggressive

# Тот же бэктест для профиля balanced и биржи Bybit
python -m bot --exchange bybit download --since 2020-01-01
python -m bot --exchange bybit --profile balanced backtest --start 2021-01-01

# Результаты по годам: просадка должна быть в рамках лимита в каждом окне
python -m bot walkforward --start 2019-01-01 --window 365

# Проверить, что всё работает, без интернета (синтетические данные)
python -m bot backtest --synthetic
```

После бэктеста в `reports/latest/` лежат:
- `report.html`: графики капитала и просадки, метрики, последние сделки (откройте в браузере);
- `equity.csv`: капитал по дням, `trades.csv`: все сделки, `summary.json`: метрики.

Что смотреть в первую очередь: **макс. просадка**, **средний и медианный месяц**,
**сколько месяцев цель 6% выполнена**, **Calmar** (доходность / просадка, хорошо > 1)
и сравнение с Buy&Hold. В консоли и в отчёте есть таблица доходности «год × месяц».

> Совет против самообмана: подбирайте параметры на одном периоде (например, 2018–2022),
> а проверяйте на другом (2023–сейчас): `--start 2023-01-01`. Если на новом периоде
> всё развалилось, значит, параметры «подогнаны».

## Этап 2. Paper trading (виртуальные деньги)

Ключи не нужны. Бот берёт реальные цены с биржи, а сделки исполняет виртуально
с комиссией и проскальзыванием, как в бэктесте.

```bash
python -m bot run --mode paper
```

- Каждые 60 секунд проверяет цены, трейлинг-стопы и лимит просадки.
- Раз в бар (по умолчанию раз в день, после закрытия дневной свечи в 00:00 UTC) пересчитывает сигналы и ребалансирует.
- Состояние хранится в `state/paper_binance_core.json`, поэтому бота можно останавливать и запускать заново.
- Журналы: `state/*_trades.csv`, `state/*_equity.csv`, лог `logs/bot.log`.

Для круглосуточной работы удобно запустить на VPS через `tmux`/`screen` или systemd.

### Управление запущенным ботом

Из второго терминала, в той же папке:

```bash
python -m bot ctl status       # капитал, просадка, позиции, стопы
python -m bot ctl pause        # не открывать новых сделок (стопы и защита работают)
python -m bot ctl resume       # снять паузу
python -m bot ctl close-all    # продать всё в USDT и встать на паузу
python -m bot ctl stop         # остановить процесс (позиции остаются, состояние сохранено)
python -m bot logs -n 50       # последние строки лога
```

Для агрессивного конфига добавьте `--config config.aggressive.toml`, для testnet `--mode testnet`.
Бот выполняет команду в течение `poll_seconds` (60 с).

## Этап 3. Testnet (настоящие ордера, тестовые деньги)

1. Получите тестовые ключи:
   - Binance Spot Testnet: https://testnet.binance.vision (вход через GitHub);
   - Bybit Testnet: https://testnet.bybit.com.
2. Задайте ключи в окружении (`.env.example` — шаблон):
   ```bash
   export BINANCE_API_KEY=...  BINANCE_API_SECRET=...
   python -m bot run --mode testnet
   ```

Бот ведёт свою «книгу»: он распоряжается только суммой `initial_capital` и
монетами, которые купил сам. Остальной баланс тестового аккаунта не трогает.
Сигналы считаются по ценам основной биржи, ордера уходят на testnet.

## Этап 4. Live (только после успешных paper/testnet)

```bash
export BOT_LIVE_CONFIRM=yes
python -m bot run --mode live --confirm-live
```

Требования к API-ключам: **только торговля, без права вывода**, с привязкой к IP.
Начинайте с суммы, которую не жалко.

## Структура

```
bot/
  config.py      загрузка config.toml
  data.py        скачивание истории через ccxt, кеш CSV, синтетика
  indicators.py  EMA, ATR, волатильность
  strategy.py    сигналы входа/выхода и размер позиций
  risk.py        защита от просадки
  core.py        общий «мозг» для бэктеста и live
  binance_public.py  публичные данные Binance напрямую (с запасным адресом)
  telegram.py    отправка сигналов и приём команд
  messages.py    тексты сигналов, статуса и отчётов
  backtest.py    бэктест (исполнение по open следующего бара, комиссии, стопы внутри бара)
  report.py      консольная таблица + report.html
  brokers.py     paper-исполнение и реальные ордера через ccxt
  live.py        цикл paper/testnet/live
tests/           pytest: нет заглядывания в будущее, лимит просадки, комиссии, live-цикл
```

Тесты: `python -m pytest`.

> Это не финансовая рекомендация. Торговля криптовалютой рискованна, и любой бот может терять деньги.
