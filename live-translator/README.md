# Синхронный перевод с телефона

Вы говорите по-русски, а телефон почти сразу произносит перевод на **английский, испанский или урду** вашим голосом.

```
Телефон (браузер)  ──звук──▶  ваш сервер  ──▶  Qwen LiveTranslate  (распознаёт и переводит)
       ▲                          │
       └────── перевод голосом ◀──┴──  режим «Qwen»: голос Qwen с клоном вашего голоса
                                       режим «ElevenLabs»: текст от Qwen → ваш клон в ElevenLabs
```

| Режим | Задержка | Похожесть голоса | Что нужно |
|---|---|---|---|
| **Qwen** | минимальная (по данным Alibaba в среднем ~2–3 с) | хорошая: Qwen клонирует голос прямо из вашей речи, заранее ничего записывать не надо | только ключ Qwen |
| **ElevenLabs** | плюс примерно 0.5–1.5 с | лучшая, особенно с профессиональным клоном | ключ Qwen + ключ ElevenLabs + ID вашего голоса |

Чтобы не ждать конца фразы, в режиме ElevenLabs каждое готовое предложение уходит на озвучку сразу.

Сервер нужен, потому что ключи API нельзя хранить в браузере. Иначе их сможет вытащить кто угодно. Сервер хранит ключи у себя, а телефон знает только пароль приложения.

---

## 1. Получите ключи

### Qwen (обязательно)
1. Зарегистрируйтесь в **Alibaba Cloud Model Studio** (международная версия, сайт alibabacloud.com) и привяжите способ оплаты.
2. Откройте Model Studio → **API Key** и создайте ключ. Он начинается с `sk-`.
3. Регион должен быть **Singapore (international)**, тогда `QWEN_REGION=intl`. Если аккаунт китайский (aliyun.com), укажите `QWEN_REGION=cn`.
4. Если ключ начинается с `sk-ws-`, он привязан к рабочему пространству. Скопируйте из того же окна значение **API Host** (вида `ws-xxxx.ap-southeast-1.maas.aliyuncs.com`) в переменную `QWEN_API_HOST`.
5. При создании ключа с включённым **Restrict Key** дайте доступ (**Access**) к **Speech to Speech** и другим голосовым и realtime-разделам. Иначе Qwen отклонит перевод. Там же можно задать лимит расходов (**Usage Limits**).

Цена: оплата за использование. По данным открытых проектов это порядка **$4 за час** разговора с озвучкой. Точные тарифы смотрите в консоли Model Studio.

### ElevenLabs (только для режима «ElevenLabs»)
1. Нужен платный тариф. Клонирование голоса доступно с тарифа Starter.
2. Создайте клон: **Voices → Add voice → Instant Voice Clone** и загрузите 1–2 минуты чистой записи своей речи. Профессиональный клон (Professional Voice Clone) похож ещё больше, но готовится дольше.
3. Скопируйте **Voice ID** клона (Voices → ваш голос → Copy voice ID).
4. Создайте API-ключ: **Profile → API Keys**.

## 2. Запустите сервер

### Вариант А: бесплатный хостинг Render (удобно для телефона)
1. Зарегистрируйтесь на render.com и подключите GitHub.
2. Нажмите **New → Web Service** и выберите этот репозиторий и ветку.
3. Настройки:
   - **Root Directory:** `live-translator`
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
4. В **Environment** добавьте переменные из `.env.example`. Обязательны `APP_PASSWORD` и `DASHSCOPE_API_KEY`, для режима ElevenLabs нужны ещё `ELEVENLABS_API_KEY` и `ELEVENLABS_VOICE_ID`.
5. После деплоя у вас будет адрес вида `https://live-translator-xxxx.onrender.com`.

> На бесплатном тарифе Render сервер засыпает после 15 минут без запросов, и первое открытие занимает до минуты. Если это мешает, есть платный тариф или другие сервисы: Railway, Fly.io. Подойдёт любой хостинг Node.js с поддержкой WebSocket.

### Вариант Б: на своём компьютере
```bash
cd live-translator
cp .env.example .env      # впишите ключи
npm install
npm run start:local       # http://localhost:8080
```
Телефон даст доступ к микрофону только по **https**. Поэтому для телефона откройте туннель, например `cloudflared tunnel --url http://localhost:8080`, и зайдите по выданному https-адресу.

## 3. Пользуйтесь с телефона

1. Откройте адрес сервера в **Chrome на Android** или **Safari на iPhone**.
2. Добавьте приложение на главный экран: в Chrome «⋮ → Добавить на главный экран», в Safari «Поделиться → На экран „Домой“». Оно будет открываться как обычное приложение.
3. В «Настройках» введите пароль приложения.
4. Выберите язык и режим, нажмите на микрофон и говорите.

**Голос в режиме Qwen:**
- *Клон моего голоса (с первой фразы)*: Qwen клонирует голос по вашей речи в начале сессии.
- *Клон моего голоса (подстраивается всё время)*: голос клонируется заново по ходу разговора.
- *Готовые голоса*: дикторы Qwen, если клон не нужен.

### Ограничения
- Экран должен быть включён, а приложение открыто. Приложение само не даёт экрану погаснуть. На iPhone Safari выключает микрофон, когда приложение уходит в фон.
- Перевод нельзя подать в звонок WhatsApp или Telegram как микрофон: телефоны не разрешают одному приложению подменять микрофон другому. Приложение подходит для разговора вживую, когда собеседник слышит телефон.
- Если перевод звучит из динамика, микрофон может слышать его. Qwen пропускает речь, которая уже на целевом языке, но надёжнее говорить в наушниках или включить в настройках «Выключать микрофон, пока звучит перевод».
- Сессия сама останавливается через `MAX_SESSION_MINUTES` минут (по умолчанию 60), чтобы не тратить деньги, если вы забыли её выключить.

## Что проверено, а что нет

Проверено автоматическими тестами (`npm test`, `npm run test:e2e`). Они используют поддельные серверы Qwen и ElevenLabs и настоящий браузер Chromium в виде телефона с поддельным микрофоном. Проверены захват звука, передача на сервер, текст оригинала и перевода, нарезка на предложения, озвучка по порядку в обоих режимах, пароль и остановка сессии.

**С настоящими ключами пока не проверялось.** Формат запросов к Qwen взят из рабочих открытых проектов, потому что документация Alibaba из среды разработки была недоступна. При первом запуске стоит проверить:
- урду в режиме ElevenLabs. Не все модели ElevenLabs поддерживают урду. Если будет ошибка, попробуйте `ELEVENLABS_MODEL=eleven_v3` или используйте для урду режим Qwen;
- модель `eleven_v4_turbo`. Если ElevenLabs её не примет, поставьте `eleven_flash_v2_5` (быстрее, но клон хуже) или `eleven_multilingual_v2`;
- если Qwen ответит ошибкой про модель, попробуйте `QWEN_MODEL=qwen3-livetranslate-flash-realtime`.

## Устройство

| Файл | Что делает |
|---|---|
| `server.js` | раздаёт приложение, хранит ключи, соединяет телефон с Qwen и ElevenLabs |
| `lib/qwen.js` | протокол Qwen LiveTranslate: настройка сессии, клон голоса, разбор событий |
| `lib/elevenlabs.js` | озвучка через ElevenLabs: WebSocket для v4 turbo, HTTP-стриминг для остальных моделей |
| `lib/sentences.js` | нарезает поток перевода на предложения для ранней озвучки |
| `public/` | приложение для телефона: интерфейс, захват микрофона в 16 кГц, воспроизведение |
| `test/` | модульные и сквозные тесты с поддельными сервисами |
