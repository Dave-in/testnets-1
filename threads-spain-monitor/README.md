# Threads Spain Monitor

Мониторинг Threads (Instagram): что сейчас обсуждают русскоязычные, которые переехали
или переезжают в Испанию, — Аликанте, Коста Бланка, Торревьеха, Бенидорм и т.д.
Нужен, чтобы делать актуальные опросы и приводить аудиторию на сайт.

Что делает:
- собирает посты по ключевым запросам (официальный Threads API или импорт файла);
- размечает каждый пост: **локация**, **интент/эмоция** (вопрос, «что купить», «а вы ходили»,
  негатив «заебало/достало/бесит», позитив, переезд) и **тема** (ВНЖ, аренда, цены,
  медицина, школы, банки, транспорт, еда, отдых, язык, бюрократия, климат);
- считает тренды: сколько постов по теме за окно, рост к предыдущему окну, «жар»
  (эмоции + позиция в TOP-выдаче Threads + лайки/ответы, если есть + свежесть);
- пишет отчёт `reports/latest.md` (+ `latest.json`) с топ-постами и готовыми идеями опросов.

Зависимостей нет — только Python 3.9+.

## Быстрый старт

```bash
python3 monitor.py demo              # проверка на вымышленных демо-данных
export THREADS_ACCESS_TOKEN=...      # см. ниже
python3 monitor.py run               # собрать + проанализировать (окно 7 дней)
python3 monitor.py analyze --days 30 # только анализ накопленной базы за месяц
python3 monitor.py fetch --query "Аликанте школа"   # разовый свой запрос
python3 monitor.py import posts.jsonl --source manual
```

База копится в `data/threads.db`: чем чаще запускать (например, раз в день), тем точнее
видна динамика тем и постов, которые держатся в выдаче.

## Вместе с Claude (скилл)

В репозитории есть скилл `.claude/skills/threads-spain-trends`. В Claude Code достаточно
написать, например:

> Что сейчас в тренде по Аликанте? Дай 5 идей для опросов.

Claude сам запустит сбор (через API, а если токена нет — через веб-поиск по threads.net
с импортом результатов), анализ и выдаст темы, примеры постов и опросы с идеями, как
вести трафик на сайт. Можно попросить запускать это по расписанию.

## Токен Threads API

1. Создайте приложение на <https://developers.facebook.com/apps> с продуктом **Threads API**.
2. Добавьте разрешения `threads_basic` и `threads_keyword_search`.
3. Сгенерируйте токен пользователя (User Token Generator в настройках Threads API),
   при желании обменяйте на долгоживущий (60 дней).
4. `export THREADS_ACCESS_TOKEN=...`

Ограничения API, о которых стоит знать:
- пока приложение не прошло App Review на `threads_keyword_search`, поиск возвращает
  **только ваши собственные посты** — для мониторинга чужих постов нужен одобренный доступ;
- лимит — около 2200 поисковых запросов в сутки (конфиг по умолчанию делает ~50 за запуск);
- лайки/ответы чужих постов API не отдаёт, поэтому популярность оценивается по позиции
  в выдаче `TOP` и по тому, сколько запусков и запросов подряд пост всплывает.

Пока доступа нет — используйте путь через Claude (веб-поиск) или `import` своего файла.

## Формат файла для import

JSON-массив, JSONL (по посту в строке) или CSV с колонками:

| поле | обязательно | пример |
|------|-------------|--------|
| `text` | да | «Как же достало ждать ситу в Аликанте…» |
| `id` или `permalink` | да | `https://www.threads.net/@user/post/…` |
| `timestamp` | желательно | `2026-09-20` или ISO-дата |
| `username`, `query`, `rank`, `like_count`, `reply_count` | нет | |

## Настройка

Всё в `config.json`:
- `search_queries` — что искать в Threads;
- `locations`, `intents`, `topics` — словари (начала слов, регистр не важен; `=слово` — только
  целое слово; у интентов есть вес для «жара»);
- `poll_templates` — шаблоны опросов по темам (`{in_loc}` → « в Аликанте», `{of_loc}` → « Аликанте»).
