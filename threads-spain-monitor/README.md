# Threads Spain Monitor

Мониторинг Threads (Instagram): что сейчас обсуждают русскоязычные, которые переехали
или переезжают в Испанию, — Аликанте, Коста Бланка, Торревьеха, Бенидорм и т.д.
Нужен, чтобы делать актуальные опросы и приводить аудиторию на сайт.

Что делает:
- собирает посты по ключевым запросам: через ваш браузер под вашим логином (`scraper.py`),
  официальный Threads API или импорт файла;
- размечает каждый пост: **локация**, **интент/эмоция** (вопрос, «что купить», «а вы ходили»,
  негатив «заебало/достало/бесит», позитив, переезд) и **тема** (ВНЖ, аренда, цены,
  медицина, школы, банки, транспорт, еда, отдых, язык, бюрократия, климат);
- считает тренды: сколько постов по теме за окно, рост к предыдущему окну, «жар»
  (эмоции + позиция в TOP-выдаче Threads + лайки/ответы, если есть + свежесть);
- пишет отчёт `reports/latest.html` — одна страница с лайками, комментариями и топ-ответами
  (+ `latest.md`, `latest.json`) и готовыми идеями опросов.

Python 3.9+. `monitor.py` работает без зависимостей, `scraper.py` требует Playwright.

## Сбор со своего ПК под своим логином (лайки, комментарии, ответы)

Официальный API пока не отдаёт чужие лайки и ответы, поэтому основной способ — `scraper.py`:
он открывает Threads в браузере на вашем компьютере под вашей сессией и читает те же
данные, что вы видите на экране.

**Windows:** установите Python 3.9+ (галочка «Add to PATH»), затем двойной клик по
`run_windows.bat`. В первый раз откроется браузер — войдите в Threads и нажмите Enter
в чёрном окне. Дальше скрипт сам пройдёт по запросам и откроет `reports/latest.html`.

**Вручную (Windows/macOS/Linux):**
```bash
pip install -r requirements.txt
python -m playwright install chromium
python scraper.py login                 # один раз: войти в Threads
python scraper.py collect               # все запросы из config.json
python scraper.py collect --limit 5     # быстрый прогон по первым 5 запросам
python scraper.py collect --query "Аликанте школа" --query "Торревьеха аренда"
```

Что попадёт в `reports/latest.html` (одна страница, открывается двойным кликом):
- вкладка **Посты**: текст, автор, дата, ❤ лайки и 💬 комментарии; сортировка по лайкам,
  комментариям, «жару», дате; фильтры по запросу, теме и эмоции;
- клик по **числу комментариев** раскрывает топ ответов по лайкам, у каждого — свои лайки и
  число ответов на него, метка «есть ответы» и фильтр «только с ответами»;
- вкладка **Запросы**: по каждому запросу — постов, сумма лайков и комментариев, самый
  залайканный пост (клик — посты этого запроса);
- вкладка **Темы и опросы**: динамика тем и готовые идеи опросов.

Важно:
- логин и cookies хранятся только у вас в папке `browser-profile/` (она в .gitignore);
- автоматический сбор формально противоречит правилам Meta. Скрипт ходит медленно, с
  паузами 2–5 сек, но не ставьте слишком много запросов и частые запуски — рискуете
  временной блокировкой аккаунта. Надёжнее использовать отдельный аккаунт;
- если Threads поменяет устройство сайта и посты перестанут находиться — напишите мне,
  парсер подстроится (он ищет посты в данных сайта по полям `like_count`, `caption`, `code`).

## Быстрый старт

```bash
python3 monitor.py demo              # проверка на вымышленных демо-данных
export THREADS_ACCESS_TOKEN=...      # см. ниже
python3 monitor.py run               # собрать + проанализировать (окно 7 дней)
python3 monitor.py analyze --days 30 # только анализ накопленной базы за месяц
python3 monitor.py fetch --query "Аликанте школа"   # разовый свой запрос
python3 monitor.py import posts.jsonl --source manual
```

База копится в `data/threads.db`: чем чаще запускать (например, раз в день), тем точнее
видна динамика тем и постов, которые держатся в выдаче.

## Вместе с Claude (скилл)

В репозитории есть скилл `.claude/skills/threads-spain-trends`. В Claude Code достаточно
написать, например:

> Что сейчас в тренде по Аликанте? Дай 5 идей для опросов.

Claude сам запустит сбор (если Claude Code запущен на вашем ПК — через `scraper.py` под
вашим логином; иначе через API или веб-поиск по threads.net с импортом результатов), анализ, откроет HTML-отчёт и выдаст темы, примеры постов и
опросы с идеями, как вести трафик на сайт. Можно попросить запускать это по расписанию.

## Токен Threads API

1. Создайте приложение на <https://developers.facebook.com/apps> с продуктом **Threads API**.
2. Добавьте разрешения `threads_basic` и `threads_keyword_search`.
3. Сгенерируйте токен пользователя (User Token Generator в настройках Threads API),
   при желании обменяйте на долгоживущий (60 дней).
4. `export THREADS_ACCESS_TOKEN=...`

Ограничения API, о которых стоит знать:
- пока приложение не прошло App Review на `threads_keyword_search`, поиск возвращает
  **только ваши собственные посты** — для мониторинга чужих постов нужен одобренный доступ;
- лимит — около 2200 поисковых запросов в сутки (конфиг по умолчанию делает ~50 за запуск);
- лайки/ответы чужих постов API не отдаёт, поэтому популярность оценивается по позиции
  в выдаче `TOP` и по тому, сколько запусков и запросов подряд пост всплывает.

Пока доступа нет — используйте путь через Claude (веб-поиск) или `import` своего файла.

## Формат файла для import

JSON-массив, JSONL (по посту в строке) или CSV с колонками:

| поле | обязательно | пример |
|------|-------------|--------|
| `text` | да | «Как же достало ждать ситу в Аликанте…» |
| `id` или `permalink` | да | `https://www.threads.net/@user/post/…` |
| `timestamp` | желательно | `2026-09-20` или ISO-дата |
| `username`, `query`, `rank`, `like_count`, `reply_count` | нет | |

## Настройка

Всё в `config.json`:
- `search_queries` — что искать в Threads;
- `locations`, `intents`, `topics` — словари (начала слов, регистр не важен; `=слово` — только
  целое слово; у интентов есть вес для «жара»);
- `poll_templates` — шаблоны опросов по темам (`{in_loc}` → « в Аликанте», `{of_loc}` → « Аликанте»).
