# Контекст для Claude

Основная работа в этом репозитории — **торговый бот в папке `trading-bot/`**.
Остальные файлы (augusta-1, torii-1, gentx) — старые testnet-генезисы Archway, их не трогаем.
Общение с владельцем — на русском.

Перед продолжением работы прочитай `trading-bot/PROJECT_NOTES.md`: там цели,
принятые решения, открытые вопросы и план. Обновляй этот файл после каждого
важного решения, чтобы следующая сессия (с телефона или ноутбука) продолжила с того же места.

Разработка — в ветке `claude/trading-bot-exchanges-pp8kid`.
Тесты: `cd trading-bot && python -m pytest`.
